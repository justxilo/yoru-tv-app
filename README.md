# YORU TV — Android releases

YORU TV is the official Android app for watching anime with your YORU
account. Your list, watch progress and settings stay in sync between
the app and the website.

- **Download:** grab the APK attached to the [latest release](../../releases/latest)
- **Website:** https://yoruwatch.vercel.app
- **Requirements:** Android 8.0 or newer, ~25 MB free space

## Installing

1. Download the APK from the latest release below.
2. Open it. Android will ask once for permission to install from your
   browser — approve it.
3. Sign in with your YORU account. Done.

## Updates

You never need to come back here manually. The app checks for new
versions on its own and offers to download and install them in place —
login, history and settings carry over untouched. Every APK here is
signed with the same key, which is what makes in-place upgrades work.

## Versions

Releases are tagged `yoru-tv-vN`, where N increases with every build.
Higher N is always newer. Release notes list what changed.

## Trust

- This repo contains **only signed release APKs** — nothing else is
  published here.
- Verify any download before installing: compare its SHA-256 checksum
  (shown next to each asset) with the value published alongside it.
- YORU TV is free. There are no paid tiers, ads, or trackers in the app.
